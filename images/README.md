# Plant photos

Drop plant photos in this folder, then reference them from `plants.js` as
`photo: "images/<filename>"`.

Naming: lowercase with hyphens, matching the plant — e.g. `butterfly-bush.jpg`.

Waiting for a file:

- `butterfly-bush.jpg` — Butterfly Bush (already wired up in `plants.js`;
  the photo appears on its profile sheet as soon as this file exists)
