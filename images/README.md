# Plant photos

Drop plant photos in this folder, then reference them from `plants.js` as
`photo: "images/<filename>"`.

Naming: lowercase with hyphens, matching the plant — e.g. `butterfly-bush.jpg`.

Waiting for a file (each is already wired up in `plants.js`; the photo
appears on its profile sheet as soon as the file exists):

- `russian-sage.jpg` — Russian Sage
- `english-lavender.jpg` — English Lavender
- `sedum-autumn-joy.jpg` — Autumn Joy Sedum
- `penstemon.jpg` — Beardtongue (dark-leaved penstemon)
- `weigela.jpg` — Weigela
